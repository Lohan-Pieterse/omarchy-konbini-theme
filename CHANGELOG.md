# Changelog

Update an installed copy with `omarchy theme update`.

## 1.5.0 — 2026-10-06

- Seven 4K wallpapers: `01-dawn-mart`, `02-ramen-street`,
  `03-stardust-shop`, `04-tower-lane`, `05-hillside-city`, `06-lakeside` and
  `07-farmhouse`
- Deep navy / warm amber palette with WCAG AA text contrast and a
  color-blind-friendly red/green
- Amber-to-blue gradient window and lock-screen borders, Yaru-yellow icons,
  amber shell controls and an amber boot/unlock logo
- Optional away screen and fastfetch logo, swapped in by a theme-set hook
- Extras for Zed, Discord (Vencord/Vesktop), Firefox, Spotify (Spicetify),
  cava, GTK4/libadwaita, Starship and lazygit
